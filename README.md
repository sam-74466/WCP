# Waterproofing Contractors Pune

Static multi-page website built with HTML5, CSS3 and vanilla JavaScript. No npm, Node.js or build step is required.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server. All site links use root-relative paths (`/`), so for local testing a local server is recommended.

## Deploy to GitHub Pages
1. Upload the complete contents of this folder to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Select the deployment branch and `/ (root)`.
4. Save and wait for deployment.
5. Configure the custom domain `waterproofingcontractorspune.com` and add the DNS records GitHub Pages provides.
6. Keep `CNAME` at the repository root with the domain name if required by your Pages setup.

## Before publishing
- Confirm that the business actually serves each area listed on `service-areas.html`.
- Replace illustrative stock imagery with genuine, permission-cleared project photographs when available. The gallery labels visuals as illustrative.
- Verify all brand links and obtain permission before using third-party logos.
- The supplied email address appeared invalid, so it has intentionally not been published. Add a verified address in `assets/js/config.js` and update the contact page.
- The enquiry form prepares a WhatsApp message. It does not upload files or store enquiries on a server. Selected photos must be attached manually in WhatsApp.
- No blanket warranty, free inspection, certification, partnership, customer count or years-of-experience claim is made.
- Review legal pages with an appropriate professional before relying on them as legal advice.

## Configuration
Edit `assets/js/config.js` for phone, WhatsApp, email and business details.

## Project structure
- Main pages: root HTML files
- Individual service pages: `services/` (33 pages)
- Styles: `assets/css/`
- JavaScript: `assets/js/`
- Branding: `assets/images/logo.svg`, `assets/icons/favicon.svg`

## External dependencies
Google Fonts and Unsplash images are loaded from their respective CDNs. The site remains build-free; an internet connection is needed for those remote assets.
